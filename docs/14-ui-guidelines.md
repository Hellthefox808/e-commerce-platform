# 14 & 15 — UI Guidelines & Design System

## Palette & Design Tokens
- **Dark Theme Tokens**:
  - Background: `--bg-primary: #0b0f19`, `--bg-card: #111827`, `--bg-elevated: #1f2937`
  - Accent Color: Violet Gradient (`#7c3aed` -> `#6366f1`) and Gold Highlight (`#f59e0b`)
  - Text Tokens: `--text-main: #f9fafb`, `--text-muted: #9ca3af`
- **Light Theme Tokens**:
  - Background: `--bg-primary: #ffffff`, `--bg-card: #f8fafc`
  - Accent Color: `--accent: #4f46e5`
  - Text Tokens: `--text-main: #0f172a`, `--text-muted: #64748b`
- **Glassmorphism Styling**: `backdrop-filter: blur(12px); background: rgba(17, 24, 39, 0.75); border: 1px solid rgba(255, 255, 255, 0.1);`
- **Micro-Animations**: Hover scale transitions (`transform 0.2s ease`), subtle toast slide-in notifications, smooth tab switches.
