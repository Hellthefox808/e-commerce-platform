# 15 — Design System Component Tokens

## Core Components
1. **Button**: Primary (Gradient Violet), Secondary (Outline Glass), Danger (Red Glow).
2. **Badge**: In Stock (Emerald), Low Stock (Amber), Out of Stock (Rose), Admin Role (Indigo).
3. **Card**: Elevated border radius `0.75rem`, box-shadow `0 10px 25px -5px rgba(0,0,0,0.3)`.
4. **Modal / Drawer**: Smooth Backdrop Overlay (`rgba(0,0,0,0.6)`), slide-in animation from right for Quick Cart.
