# 04 — User Stories

| ID | As a... | I want to... | So that... | Acceptance Criteria |
| --- | --- | --- | --- | --- |
| **US-01** | Customer | search products by keyword and filter by category/price | I can find items quickly | Real-time filter results, clear visual counters |
| **US-02** | Customer | add items to my cart and apply promo codes | I can review discounts before paying | Instant price recalculation, clear item summary |
| **US-03** | Customer | pay securely using Stripe or Razorpay | My transaction is safe and confirmed | Gateway selection modal, tokenized payment verification |
| **US-04** | Customer | view my order history and live delivery status | I know when my package will arrive | Status timeline (`PENDING` -> `DELIVERED`), order ID search |
| **US-05** | Seller | add and edit my product listings and stock counts | I can keep catalog inventory up to date | Stock validation, instant catalog update |
| **US-06** | Admin | view revenue analytics charts and audit logs | I can monitor business performance and platform security | Revenue graphs (Recharts), audit log table with filters |
