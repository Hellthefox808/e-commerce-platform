# Contributing to LuxeCommerce

Thank you for your interest in contributing!

## Development Workflow
1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Follow the architectural principles outlined in `docs/06-system-architecture.md` and `docs/12-coding-standards.md`.
3. Ensure all code passes typechecks and unit tests.
4. Submit a Pull Request targeting `main` with detailed verification steps.

## Code of Conduct
Respect all community members. Maintain clean, well-documented code.
